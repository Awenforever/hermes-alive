# ADR0198 — Trace cited sources before turning commentary into a share

Status: implemented; qualification pending

## Evidence and responsibility

The real installed discovery trial completed, but its selected evidence was a
secondary interpretation. Two private native authorship contrasts improved
voice/links without curing unsupported generalizations. A public-only native
investigation retrieved original material; its first run exhausted its turn
budget and is not a completed research proof. A separate no-tools completion
over those retained raw observations finished normally. Its tentative research
notes still contained speculative explanations, and the subsequent private
writer both copied and strengthened some claims. None is a clean quality round.

Do not solve this by another persona prompt, topic-specific blacklist, shorter
word limit, or another model judge. Better sources and preserving epistemic
scope are necessary; neither can guarantee truthful or useful communication.
No private experimental AIAgent/global-hook patches enter the Gateway.

## Bounded installed capability

After additional explicit cited-read consent, the existing selected-result
extracts can feed one Core-owned model call that may
select at most two distinct unread HTTP(S) links actually cited verbatim in
those retained extracts, or record a reason to stop. The input contains public
evidence only: no owner context, private inquiry question, inferred interests
or proposed assignment to the recipient. No new search is available. There is
one hop, not an open crawler or loop until a favored answer appears.

The model assesses whether an original source could resolve a material question;
the code checks exact link provenance, bounds and non-repetition. Neither link
existence nor a domain name proves authority. Core still checks URL/secret/DNS/
SSRF policy immediately around actual IO. Failed reads retain failed outcomes;
they do not become verification, fresh evidence, or a reason to retry silently.

Reuse the existing encrypted reading-choice receipts, HostDiscoveryReader,
Core model facade and pending-physical-read lifetime. The follow-up choice is
bound to its exact original-read receipt, prompt/input, sources and served model.
Owner context/consent remain current across waits, without including private
context in the public-research input. The reason remains an encrypted model
note, not a source observation, user memory or writer instruction. Actual new
extracts enter the normal evidence/planning/expression/final-assessment path.

## Recovery, history and qualification

`kernel-setup --confirm-cited-reads` requires the existing explicit public-query
and public-read consent as well. It persists `follow_citations: true` inside
that disclosure scope. Absent confirmation stays absent through normalization
and upgrade; initial public-read consent alone does not expand to cited URLs.
Changing this scope changes the existing host/config/model currentness binding.

A new durable cycle mode is recorded before initial search. A cycle whose old
search already started without this marker retains its old path; upgrading must
not retroactively add IO/model calls to a historical operation. Completed new
choices/reads replay without IO/inference. Interrupted/failed choices require
reconciliation. Revoked consent, forgotten context or erased evidence cannot
reuse the choice. Existing physical pending guards remain unchanged.

Controlled tests must cover cited original evidence reaching planning, a link
beyond the old1800-character excerpt, no private context in the follow-up,
abstention, failed read, invented/truncated/foreign/repeated links, consent and
source/context withdrawal, interrupted follow-up, exact new replay and old-mode
replay. The actual Core CLI/install/hook probe now includes this additional
SDK-admitted stage; its model/tool responses remain synthetic.

This improves acquisition, not a proven semantic boundary or full Alive. Real
fresh content still needs manual assessment: inference labels do not license
unsupported assertions. Source-to-writing fidelity, sustained agenda, noisy and
external memory/Halo/erasure, feedback/outcomes/reflection, novelty/exploration,
portability/migration/rollback and ten fresh complete clean quality rounds all
remain open. No production change, send, main/release or deployment is implied.
