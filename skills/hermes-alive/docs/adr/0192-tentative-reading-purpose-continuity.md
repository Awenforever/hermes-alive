# ADR0192 — Keep a revisable reading purpose through discovery and composition

Status: implemented connection; qualification and useful autonomous loop pending

## Evidence and decision

The actual main-model directed reading experiment retained sources but discarded
the reading question before composition. A single private contrast carrying that
question improved coherence somewhat, but still produced inventory-like text.
This is a continuity defect, not proof of causality or a stable style fix.

Reuse AgendaProjection MODEL_PROPOSAL OPPORTUNITY and its encrypted content
vault. DiscoveryInquiryContext stores a bounded question and value hypothesis,
the proposing model actor, current owner-bound observation references and an
expiry no later than those sources. It creates no user fact, preference,
commitment, search permission or delivery grant. Revision withdraws the old
proposal and records a new identity; completed inputs are never rewritten.

The trusted host explicitly pins up to four task identities into an already
authorized HostDiscoveryReader read and into PlanningRuntime (also forwarded
through ExpressionRuntime's existing planning parameters). No automatic global
task lookup or separate scheduler/queue. Sources retain their own listing versus
page-extraction provenance; a question is never a new evidence source.

Both read requests and interpretation receipts bind the task snapshot. Current
agenda scope, proposal actor/authority/content digest, live source evidence and
expiry are checked. Task changes across awaits or recovery invalidate affected
work; completed planning recovery cannot call a model again. Old operations
without task context keep their original semantics. Expression and source-review
paths continue to revalidate the original synthesis, not a copied permission.

## Validation scope and remaining work

Controlled encrypted integration exercises actual agenda, host read, synthesis
and planning: exact reopen without tool/model repeats, cross-owner and clearance
refusal, task withdrawal, task erasure, source erasure and withdrawal during a
model wait. Synthetic model/tool results are wiring evidence, not useful sharing
or a fresh quality round. Canonical package/full regression pending at writing.

This does not yet assemble autonomous search/reading choices in the installed
host. Next qualify a fresh public-source/real-model vertical path, then integrate
the bounded discovery stage into the consented host loop. No production deploy,
private chat import, FIFO ownership change, independent-review claim or acceptance
round credit. The original long-term memory, sustained agenda/outcomes/reflection,
Halo, migration/portability and ten fresh clean rounds remain required.
