# ADR 0239 — Restore the continuous-agent scope at the actual entry

Status: candidate; integrated source-free verification pending.
Date: 2026-10-26.

## Problem found in the execution path

The original objective is experience → interpretation → memory/belief → intent →
decision → authorized action → outcome → reflection/learning. Sharing is one
behavior. Recent live examples and qualification concentrated too heavily on
content discovery, and their length/tone still resembled publications.

The imbalance is also present in code: kernel_execution_bridge.enable rejected
configurations with no public_queries; assemble unconditionally constructed
ConfiguredDiscoveryCycle. Existing commitment cognition, agenda transitions,
non-communication action types and reflection tests do not prove that an actual
installed user can use them. Code presence is not functional integration.

## Decision

Remove public discovery as a prerequisite to activation. Keep canonical target,
model/delivery consent, history retention, policy, dispatch cadence and action
authorization intact. Assemble the existing phased discovery preparer only when
public queries were explicitly configured. Otherwise use a small agenda-only
preparer that binds the same qualified authorization and performs no public IO;
the same Native/agenda/reconsideration/standard adapter pipeline still operates.
No second scheduler, provider router, physical queue or new agent framework.

Do not use a silence control to claim the full agent works. Verify a source-free
installed sequence: no-query setup/owner confirmation/activation; idle silence and
unchanged wait; admitted agenda fixture; reminder selection/composition/local
submission; owner completion; no repeated reminder; pause. Mark the owner input
fixture, controlled model and in-memory adapter explicitly. Natural-language
intake, actual model behavior, real transport, process restart, tool-action and
longitudinal learning each still need their own integrated evidence.

## Full acceptance remains broader

- Exact and retractable experience/memory, with owner, origin and uncertainty.
- Carry unfinished commitments without confusing ideas or third-party statements
  with instructions; follow up, ask, snooze, finish and stop appropriately.
- Meaningful authorized initiative and actions with observed outcomes, including
  quiet behavior; no need to manufacture news as the reason to wake up.
- Continuous conversation after unsolicited contact and across compaction/restart.
- Attributed feedback and reflection that can alter later decisions without
  turning a single evaluation into a permanent interest or invented preference.
- Natural brief unsolicited conversation; requested depth remains available.
- Independent model/channel inheritance, portable install/upgrade/uninstall/
  reinstall, preserved data and associations, rollback and production acceptance.

Ten fresh sharing rounds remain a required subgate, not a replacement for this
behavior matrix. No fixed character quota or extra style judge is introduced.
The unfinished quoted-feedback prototype is saved separately in Git WIP; it
must not accidentally enter this change or be advertised as live learning.

## Typed continuation source defect exposed by the source-free path

The first source-free reminder sequence submitted successfully, but its followup
reference labeled the original agenda request as unavailable: continuity assumed
that every source was a web observation in the discovery vault. An actual-Core
regression now fails on the missing original constraint. Keep this failure,
rather than counting a successful local send as complete continuity.

Capture a host-derived admitted_commitment_v1 reference kind only from the
already-validated cognitive evidence window. Resolve it through the typed
agenda's established vault and purpose, with canonical event/owner/content checks.
Missing storage is unavailable, never permission to create replacement keys.
Present the original request as historical context, not current pending state or
new action authority. Explicit erasure of its typed source also invalidates the
derived outward reference; ordinary completion does not erase historical context.
Unmarked historical reference formats and web sources retain their existing path.

## Focused qualification, 2026-10-26

Supersedes only ADR0213's initial public-query activation prerequisite; all other
authority, cadence, explicit public disclosure consent and execution boundaries
remain. The implementation passes four current-Core suites on frozenr110:
source-free agenda/continuation/missing-storage/erasure, existing execution and
source wait/refinement controls, full controlled discovery, and existing paged
share/source continuity. Synthetic inputs/models and local adapters are explicit.
The new regression first failed on the old typed request resolving as unavailable
(r109). The first no-query test also exposed a noncanonical Telegram fixture
alias (r107), corrected to a canonical numeric target before these claims.

These prove the actual installed execution wiring rather than natural user-intent
admission, real model judgment, non-communication tool autonomy, daemon restart,
longitudinal reflection, four-device distribution or production acceptance.
Those are outstanding, not waived by the restored entry. Full current portable
regression is running separately. Do not resume unlimited writing comparisons
while these whole-agent integration gaps remain.
