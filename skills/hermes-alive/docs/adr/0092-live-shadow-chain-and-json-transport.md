# ADR 0092 — Live composed shadow evidence is not source-support qualification

Status: real composed no-send experiment; one review failure; no production qualification.

## Composed experiment, not separate canned components

Two fresh public synthetic contexts use actual configured models for opportunity
interpretation, selection, Chinese expression and a different-family fidelity
review. Profile fixtures express bicycle-maintenance or language/speech interest
and current availability; each offers a relevant practical source plus unrelated
industry figures. IDs/URLs use opaque numeric fixture labels. No expected verdict
or selected candidate is supplied to the models. Candidate authority defaults NONE;
there is no authorizer, outbox transport, actual recipient or feedback learning.

The private probe imports the current kernel and calls Hermes auxiliary routing.
Main USTC DeepSeek is selected by the isolated primary profile. The two review
calls use the separately read-only exported, already configured Qwen3.5 entry,
including its own configured endpoint/credential, not a production model change.
Existing official DeepSeek fallback remains configured; actual routes are recorded.
Family independence is diagnostic and not independent-provider or ground-truth proof.

Eight logical calls observe eight HTTP 200 requests to api.llm.ustc.edu.cn. Both
interpretations produce one share and one non-action; actual selection chooses
share in both, and actual expression preserves the source URL. Six calls report
deepseek-flash/custom:ustc; two report qwen3.5/custom. The language recording case
obtains shadow_eligible review, explicitly safe_for_automatic_delivery=false.
The bicycle review returns JSON inside a Markdown code fence and fails the old
strict parser. Its original failed comparison stays failed, not silently retried.

## More important semantic finding

The bicycle interpretation adds examples and an operation absent from the source:
glass/stones/thorns, cuts/bulges/casing damage and careful removal of debris. Those
may be reasonable common knowledge or tentative advice, but their source support
and attribution are not established. The language expression uses wording akin
to online watching even though the recording medium is unspecified. This could
be pragmatic wording rather than a confirmed material error; it needs assessment.

Fidelity review compares expression to the already generated draft, not that
draft to the discovery source. Its raw positive verdict cannot establish source
support, relevance, calibrated confidence or usefulness. SourceSupportReviewer
already exists in bounded shadow mode and must be composed/evaluated separately;
do not add tyre/video keyword filters or turn generic helpful reasoning into a
blanket forbidden category. The next semantic path should distinguish sourced
facts from explicitly tentative contextual suggestions and material added claims.
The default runtime source-support method remains unchanged and unqualified.

## General JSON transport correction

Four adjacent decision stages now share parse_model_json: opportunity synthesis,
selection, semantic fidelity findings and source-support findings. Plain JSON or
one complete outer unlabeled/JSON code fence are accepted with identical decoded
values. Only the enclosing presentation is removed. No bracket insertion, field
completion, prose extraction, alternate schema, semantic rewriting or permission
default is introduced. Unknown labels, extra prose/multiple objects/fences, duplicate
keys at any depth, nonfinite/overflowing numbers and broken JSON remain rejected.
Character budgets remain explicit and nesting has a 64-level boundary; business
schemas and independent action/source checks remain downstream and unchanged.

This is transport normalization, not deterministic rendering as model fallback.
Original raw reports and failed receipts are not rewritten. The new parser's
ability to read the old fenced output is not a new model run or a completed review.
No source verdict, automatic delivery or learned preference is invented by parsing.
Removed duplicated JSON-key handlers rather than stacking per-provider exceptions.
Feedback interpretation/recovery and other stages not migrated to this parser
are not claimed fixed by this change; their persistence contracts need separate audit.

## Next critical path and full scope

Compose source-support assessment with the selected draft and natural expression,
retaining uncertainty and distinguishing reasonable advice from claimed source
facts. Qualify useful attributed outcomes and bounded feedback learning rather
than declare success from fidelity/formatting alone. Genuine host ingress/grants/
delivery, layered/external memory, sustained agenda/adaptation, physical forgetting,
migration/rollback, portable lifecycle and production acceptance remain required.
