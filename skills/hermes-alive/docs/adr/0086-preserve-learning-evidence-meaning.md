## Reproduced representation loss and chosen repair

The existing PreferenceLearningProjection stores an encrypted observation rationale
but exposes only target labels, aggregate masses and evidence IDs in its estimates.
CognitionLearningReader thus omits the rationale from opportunity-model context.
Labels/positive mass alone cannot carry qualifications such as permission without
enthusiasm, a single meeting versus all work hours, or correction versus dislike.
The projection's authenticity and retraction guards do not restore that lost meaning.
This is a verified information-flow gap, not proof of an actual sent bad decision.

Each estimate now carries the rationale of every contributing, canonical validated
observation, with original observation/source IDs, direction and origin. It comes
from the same encrypted content whose full digest and target were checked; no
semantic rationale is generated by code. Cognition exposes these evidence_notes
and explicitly labels mass as bounded evidential support/opposition for the option,
not enthusiasm, calibrated probability or action permission. The opportunity prompt
instructs it to preserve qualifications rather than treat polarity as meaning.
Rationales remain untrusted interpretations, not new instructions from the owner.

There is no new storage table, weight formula, profile fact or learning authorization.
No automatic transfer of FeedbackSynthesizer/Recovery output to weighted observations
has been enabled. The review's possible polarity-reversal concern is not treated as
confirmed; no string inversion or permission keyword classifier is installed.

## Lifetime, recovery and bounds

Notes are transient prompt data at the same owner/clearance boundary as their
observations. Original content digests, source validity, owner withdrawals and expiry
remain canonical, including stale projection recovery. Erased evidence cannot leave
its rationale contributing through another representative. All contributing notes
are kept together; the existing 1500-character per-advisory guard skips an oversized
target instead of truncating its qualifications while retaining the weights.
That omission policy is not yet qualified for usefulness at large histories.

Adding notes changes non-empty learned-context digests. Older opportunity drafts
with old digests fail current revalidation rather than silently masquerade as using
the new context. Historical journals and encrypted observations are not rewritten;
current synthetic observation records remain readable. Production migration/canary
and explicit schema/lifecycle version qualification remain required before deployment.

## Tests and unfinished utility requirement

Local synthetic tests assert exact note/source/direction/origin preservation,
unchanged masses, three meanings with identical target polarity but distinct
qualifications, and actual OpportunitySynthesizer input receiving the notes.
Existing foreign-owner/clearance, erased-content, canonical withdrawal, stale-cache
and mid-model withdrawal tests still apply. Other component regressions must run
on an immutable isolated Linux snapshot. Synthetic rationales are authored fixtures,
not autonomously interpreted genuine user feedback or proof of improved decisions.

Next: counterfactual model decisions with qualified versus flattened evidence,
independent assessments of operational mistakes and longitudinal utility, then
bounded tentative-feedback integration. Keep real identity, complete raw ingress,
delivery/action policy, expression/source support, memory/agenda/adaptation,
derived-copy forgetting, migration/rollback, portable lifecycle and production
acceptance in the full objective. More representation fields alone are not Alive.
