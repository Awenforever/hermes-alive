# ADR 0090 — Fresh decision evidence and host-owned source-link continuity

Status: experimental component change; semantic and full-chain acceptance unproven.

## Fresh prospective contexts

Three authored public synthetic pairs cover narrow astronomy interest versus an
unrelated science announcement; an eligibility-restricted art workshop versus an
unrestricted guide; and useful recording advice versus an unverified plugin page
with embedded instructions to ignore the owner. Exact constraints predate calls,
but are not supplied to the model. Case names stay out of model IDs/URLs. Source
order reverses in the middle pair; canonical memory/vault clones and weights match,
with only learning notes removed from one arm. Clocks differ sequentially.

Each case has two explicit fixture memories and two discovery sources. These are
not private user facts, authenticated ingress or learned production preferences.
Windows and isolated Linux fake parity tests check all three scenario sets, role
identity binding, source coverage and no sends or new preferences. Fake source
choice is not semantic competence.

All six actual calls return HTTP 200, deepseek-flash/custom:ustc. Each structurally
accepts one relevant share and one skip, with no rejected or unassessed unit. No
installation, automatic settings change, user eligibility or personal obligation
is asserted. Both arms are similar; evidence-note superiority remains unproven.
Six protocol successes are not six zero-error complete Alive calls.

Engineering review notes a missing URL in the flattened astronomy draft and an
overbroad qualified eligibility rationale: it says sharing/asking would require
inventing facts or pressing on an unstated detail. A conditional share need not
invent eligibility, though skipping is also a defensible low-interruption choice.
The audio drafts' 'no settings changes needed/suggested' framing also needs
pragmatic assessment: making headroom may in practice involve recording settings.
Do not write per-topic keyword repairs or label every conservative choice wrong.

## Blinded different-family diagnostic is not a qualification gate

One Qwen3.5/custom:ustc call reads six opaque, shuffled row IDs with common full
source/profile/feedback reference, raw proposals and retained outputs. Author
constraints, expected outcomes, semantic case names and arm names are excluded
from its input; the decoding map stays outside the model prompt. It observes
HTTP 200 and labels all six acceptable in its retained raw text. It misses the
engineering concerns above. Different model family is not independent provider,
ground truth, calibrated judgment or proof of material-assertion coverage.

The response is wrapped in a Markdown JSON code fence. The strict diagnostic parser
records JSONDecodeError and no completed review. The original failed report is not
rewritten or retried. Its readable raw judgments can be discussed, not promoted
to a successful automatic gate. Mechanical wrapper extraction would be a transport
normalization, not semantic repair, but was not used to change this result.

## Reproduced source-link architecture defect and correction

OpportunityExpressionStore protected the original URL only when the drafting
model already included it. Consequently a syntactically valid no-link draft could
be selected and expressed without any deterministic provenance requirement.
This defect is independent of topic, keyword or model.

Now canonical owner-scoped selected-source provenance enters meaning as a separate
LINK atom when absent from the immutable selected draft. The first PROPOSED_CONTENT
atom and frame/action contract remain unchanged. If already present, the original
single-atom path remains. Rendering can integrate the URL naturally as a hyperlink,
but the exact literal cannot disappear. No factual interpretation, preference,
destination or authority is fabricated. Selection/current source/profile/learning
binding and expiry/erasure checks remain.

LINK text/literal bounds align with discovery's 4096-character source-URL bound;
other atom bounds are unchanged. No truncation or replacement URL is allowed.
Tests cover omitted-source recovery, renderer omission rejection before review,
3900-character URL path, exact draft preservation and immutable selection frame.
Old retained meanings missing required provenance are not silently rewritten;
their mismatch fails closed and requires a new explicit interpretation/selection
path. Data migration and full lifecycle qualification remain open, not assumed.

This protects expression meaning, not the original direct action contract or all
possible dispatch paths. Original draft delivery still needs a host-owned source
presentation contract or equivalent qualification. It is not proof that messages
always contain links in production, nor that source-linked claims are true.

## Next critical path

Calibrate per-decision semantic/source support, including conditional usefulness
versus excessive restraint and unsupported pragmatic additions. Avoid requiring
useful uncertainty to be resolved only through questions or suppressing it all.
Integrate canonical source presentation through the chosen delivery path, then
qualify attributed outcome/feedback learning. Full authenticated host ingress and
delivery, layered/external memory, sustained agenda/adaptation, physical forgetting,
migration/rollback, portable lifecycle and production acceptance remain required.
