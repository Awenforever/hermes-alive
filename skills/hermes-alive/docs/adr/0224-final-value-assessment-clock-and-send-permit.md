# ADR0224 — Final value assessment clock and send permit

Date: 2026-10-24 (Asia/Shanghai), Codex.
Status: implemented; qualification in progress.

The real public VISTA replay completed nine logical auxiliary calls and one
wording repair. All final checks were positive, yet actual authorization denied
selection_stale. Its fixed five-minute age measured from selection, before lengthy
composition and checking. A successful local wrapper did not mean a submission.

Keep the default selection-age guard and the existing short physical permit.
The final discovery source/recipient-value assessment now receives a frozen host
review_as_of clock distinct from the earlier interpretation timestamps. Retain
the method marker in start/completion and exact clock in protected review input.
Verification reconstructs that input clock from canonical scope-checked history;
protocol correction does not renew it. Old unclocked review records remain valid
history but cannot claim this fresh value assessment.

After exact wording has a supported current source/value witness, an older
delegated share/ask may qualify against that assessment's still-bounded age.
Other action kinds and authorities do not gain an exception. A newer inbound for
this owner prevents it; another owner's input does not. All existing source,
context, agenda, policy, delegation, route, meaning, final-wording and sensitivity
checks remain. A review from the future, erased evidence, copied/retimed proof,
missing witness or unsupported assessment cannot qualify. No selection is
rewritten, no advice becomes a sending grant and no send happens during review.

Actual authorization still mints the normal 30-second permit (maximum60), capped
by the qualifying review window when the exception is needed. Reopening an expired
permit cannot renew it. A long or expired final review still fails conservatively;
there is no universal staleness bypass, hidden model retry or second physical FIFO.

The synthetic clock regression uses actual encrypted planning, final assessment
and authorization APIs. It covers delayed composition, historical unclocked
records, near-boundary permit capping, expiry/replay, future/retimed review,
missing witness/delegation and owner-input isolation. No external send/model.
The public model regression and useful conversational quality remain separate
acceptance requirements; a positive review or authorization is not delivery.
