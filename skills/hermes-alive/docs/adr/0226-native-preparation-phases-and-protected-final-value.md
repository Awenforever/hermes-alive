# ADR0226 — Actual native phases and current protected final meaning

Date: 2026-10-25 (Asia/Shanghai).
Status: native phase fix qualified; protected final-review extension under qualification.

The ordinary installed Core assembler wrapped the discovery preparer but hid
observe/reason/restore_parameters and bounded retry. Direct host tests therefore
proved a different integration path. The actual installed-native reproduction
performed four model calls on unchanged input rather than waiting after two.
Forward the phases and retry capability, bind original authorization metadata
before the cadence guard, and retain runtime revalidation. Use the existing
trusted CoreContextRead only for the separately confirmed private-profile option;
check context before and after selection inference. No second queue or Core patch.

Actual installed-native tests must exercise unchanged waiting, current profile
replacement/deletion, admitted inbound wakeup, cooldown without source/model work,
and pause without dispatch. Preserve the failing frozen reproduction. Presence
of methods or success of directly injected preparers is insufficient evidence.

A real public-news run selected a valid version2 warning with protected price
and charging deadline. Slow expression made the selection older than five
minutes. Its final generic fact review did not reassess current recipient purpose,
so selection_stale correctly refused it. Do not force warnings into version3
editorial briefs, relax expiry or treat review completion alone as fresh value.

For version2 final expressions, combine source, protected meaning and current
recipient-purpose assessment in the existing final review call. Retain the plan,
speech act, conditions, uncertainty, literals and factual negation. Distinguish
this from version3 editorial freedom. The authenticated review-start-v1 clock
qualifies only the exact current expression; missing, copied, retimed, expired or
negative findings grant no extension. Original owner input, delegation, route,
policy, source and short physical permit checks remain unchanged. Old generic
fact-only evidence cannot be promoted into this new assessment. Version1 is not
upgraded by assumption. No source-specific exception or additional model stage.

Qualification must include delayed protected warnings, unchanged old selection,
short permit expiry, no-delegation refusal, new-owner-input refusal, future or
forged clocks and missing witnesses. Synthetic approvals establish protocol
boundaries, not semantic quality. Real public-source/model runs and the final
ten fresh useful full-chain rounds remain separate gates.
