## Continue completed work, not duplicate it

ADR0163's r10 independently reviewed a retained failed candidate with actual
qwen3.8-reasoner/custom:ustc. Its canonical receipt is reusable only while its
source, context, prompt version, findings, terminal history and independence
remain valid. `SourceSupportReviewer.load_current` performs that verification
before recovering a typed receipt; persisted labels alone are insufficient.

and never becomes independent by recovery.

The opt-in retained probe can copy an existing case and consume its exact
review receipt, validating it before reading model credentials. This avoids
another model review solely because a session or operator changed.

## One explicit host stage budget across composed cognition

Standalone review supports host-selected timeouts, but composed planning and
expression previously hid their separate fixed defaults. The embedding host may
now explicitly supply `model_timeout_seconds` (finite nonbool numeric [1,240]).
It is validated before planning reads/spend, bound to operation identity, and
reaches interpretation/correction waits, source/purpose review, and semantic
render/review. Unspecified preserves existing60/40-second stage defaults. This
is not a model-specific allowance, a provider retry, or permission to widen the
owned native process lifetime. That lifetime still independently clamps calls.
The isolated operator additionally supplies a bounded native per-call timeout;
selection has no independent new retry or timeout implementation.

Tests cover invalid budgets before additional inference, propagation to review/
render, identical completed replay, and denial when the same operation changes
budget. Source/history tests also recover a canonical receipt through a new
reviewer and reject erased or foreign evidence and implicit correlated promotion.

## A deeper fault exposed by actual wording

The plan includes an internal collection-log attribution as recipient content.
The illustrative draft omits it, so the purpose reviewer approves the draft's
omission while overlooking that the actual plan retains it. The renderer then
faithfully emits the unwanted planned unit. This is not a renderer omission or
something to strip after selection/approval.

Interpretation now names collector data `provenance_metadata.collector` rather
than an ambiguous top-level `source`. That persisted collector remains available
for audit/uncertainty, not promoted into public publisher/author evidence. The
plan guidance distinguishes those roles without any keyword replacement rule.
Purpose assessment v2 consumes only the recipient communication plan, removing
the illustrative text from its review input. It must assess every unit the later
renderer will actually preserve. Prompt/snapshot versions change, invalidating
old purpose receipts rather than relabeling them as new-method passes. Source
support remains separately evaluated against evidence and context.

Natural rendering can use compact Markdown lists and descriptive inline links,
but must preserve all protected literals and material meaning; no post-render
heuristic deletes inconvenient provenance or caveats. Regression checks assert
collector namespace separation and purpose input without illustrative text,
including commitment-purpose correction. Five adjacent source/history/expression/
interpretation/commitment entries pass offline under installed Hermes.

The prospective native-public-expression-real-20261017-r2 case completes six
calls under this changed method: DeepSeek generation/selection/render and actual
USTC Qwen3.8 source/purpose/semantic reviews. It selects a share, uses an inline
link, omits the internal collector line and reopens without another model call.
The original r1 failure is not overwritten. This proves the composed expression
and recovery path, not full final-evidence quality or useful long-term behavior.
The final phrase '我只核实了…' raises an actor-attribution concern: an external
operator gathered the observation, not an evidenced action by this isolated
Hermes. Keep this concern rather than counting a zero-error round.
