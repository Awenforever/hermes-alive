# ADR 0094 — Source-support assessment must bind final expression

Status: isolated implementation and actual retained-expression diagnostics;
no qualified automatic semantic admission or production deployment.

## Gap and implementation

SourceSupportReviewer previously reviewed only an interpretation candidate.
Fidelity to that draft did not establish source support for later expression.
ExpressionSourceSupportReviewer now reuses the same lifecycle while supplying
the exact retained model expression as the candidate. It does not inherit the
ancestor's source-support verdict or rewrite any expression/action contract.

Scope is checked before encrypted expression resolution. The expression store
verifies integrity, current selection/meaning binding, source validity and expiry.
The supplied interpretation must contain the expression's original selected
opportunity candidate. Snapshot bindings record the selection, meaning and
interpretation receipt, and explicitly mark the draft as not evidence. Source and
current context come from the existing bounded source snapshot, not model wording.
The original-draft authority remains unchanged.

Review independence is checked against the expression renderer's actual model,
not the earlier drafter. Start causation names the expression event; encrypted
review retention follows the expression's expiry, not a longer-lived discovery.
Pre/post-call snapshots and later verification revalidate the same bindings. A
new selection, erased source or expired expression invalidates the receipt. An
operation is spent even after failure and cannot silently call again. Receipt
types still grant no delivery authority or proof of world truth. This adapter
is not yet a production host scheduler or an automatically trusted semantic gate.

## Tests and uncovered older-fixture defect

Six synthetic contract scenarios exercise final-text capture, foreign scope,
wrong interpretation/target, actual-renderer self-review rejection, supersession
during review, source erasure during/after review, expiry-bound resolution,
expression-limited retention and spent-operation rejection. Expiry-after-review
uses the real resolver with as_of equal to the expression expiry; it does not
wait an hour or claim a production clock/lifecycle test. No sends or action attempts.

Windows expression-support, claim-support and faceted-claim-support suites pass.
First isolated Linux batch passes expression_support and source_support, then
fails claim_support because its authored quotation ledger covers only the raw
draft and omits the newly canonical source link from ADR-0091. The coverage guard
correctly rejects the tail. That failed batch remains failed. Updated diagnostic
fixtures to cover the actual presented candidate: claim units now include the
canonical provenance link, and facet segments use full presented text. No runtime
coverage guard, authority or source-presentation policy was weakened.

## Actual expression reviews and remaining semantic limitation

The two ADR-0092 expressions were still current and were checked in a network-none
carrier before exporting a temporary diagnostic profile. The bicycle expression
exists despite its original fidelity-review parser failure; reviewing its sources
is a distinct new operation, not retrying or relabelling that failed review.
No interpretation, selection or expression generation was repeated.

Both actual Qwen3.5/custom:ustc reviews complete and verify current. Two observed
HTTP requests to api.llm.ustc.edu.cn return 200. Both verdicts are supported with
empty concern lists. The snapshots contain complete Chinese expression, including
the added bicycle suggestions and the recording's online-watching wording. The
positive reasons still summarize globally rather than account for attribution of
those details. Possible reasonable background advice/pragmatic wording must not be
declared false merely for absent literal wording, but the output likewise does
not establish their attribution, materiality or calibrated confidence. Connecting
the final-text review closes a scope defect, not the model-judgment qualification.

Next compare source assertions, contextual/model-originated suggestions and ambiguous
pragmatics with inspectable reasoning on fresh diverse positive and counterfactual
cases. Prior richer claim/facet prompts are diagnostic alternatives, not proven
superior defaults. Do not add bicycle/media word filters, regenerate away the
retained evidence, or call reviewer agreement automatic truth. Broader useful
authorized host outcomes and longitudinal feedback still matter, not only reviews.
