# ADR 0088 — Discriminating advice controls reveal a missing decision distinction

Status: observed component evidence; no automatic learning or production qualification.

## Prospective experiment

Three fresh authored public synthetic cases add explicit baseline interests,
current availability, and a boundary against shopping advertisements. Each has
one relevant practical source and one commercial negative control. Source order
reverses in the middle case. Canonical fixture journals/vaults are cloned before
calls; only source-linked learning notes are removed from the flattened arm.
Both retain masses, mass semantics, explicit context, prompt and source facts.
Semantic case names are excluded from model-visible IDs/URLs. Order alternates;
sequential clocks still differ. Constraints were authored before the calls.

These are synthetic authored memories, not real user preferences, authenticated
ingress, autonomous feedback learning or delivery permission. Fake regressions
check matched inputs, opacity, source-role traceability, three explicit memories,
no new preference observations and no dispatch. A fake choosing the first source
is not a semantic policy oracle.

## Actual outcomes

Six logical calls observe six HTTP 200 responses from api.llm.ustc.edu.cn,
deepseek-flash/custom:ustc. All pairs match except notes and clock. Every arm
accepts a share for its relevant source. No arm accepts an advertising share.
The plant-care shares retain the species qualification. The repair shares do
not treat an old meeting as a permanent interruption ban.

Two responses nevertheless contain an empty-text advertising share, with
dimensions explaining why the advertisement should not be shared: flattened
route case and qualified plant case. Those units are rejected by the current
nonempty communication contract. These are neither useful drafts nor deliberate
silence receipts, and their original partial results remain partial.

The flattened plant case also accepts an ask proposing to reconfirm the user's
already explicit no-advertising boundary. It is structurally valid but appears
redundant and itself surfaces the excluded commercial content. This is a human
engineering assessment, not independent semantic adjudication or a demonstrated
effect of removing notes. One sample per arm, obvious synthetic sources and
strong explicit baseline context do not establish causal or longitudinal benefit.
Do not turn six HTTP successes or six relevant drafts into six clean Alive runs.

## Architectural consequence, not an advertisement patch

The current synthesis vocabulary exposes share/ask communication candidates and
an empty aggregate list, but no source-linked, reasoned decision to skip one
opportunity. This can pressure the model to encode non-action as an empty draft
or unnecessary clarification. Preserve the current failed/partial evidence;
do not reinterpret malformed output retroactively as successful abstention.

Next design a separately evidenced per-opportunity decision layer: communicate,
ask only for a material unresolved decision, or abstain with a bounded reason.
An abstention must not become an executable action, a permanent preference,
successful delivery, or evidence of user dislike. Missing decisions remain
unassessed; malformed ones remain rejected. Current explicit preferences should
not be reconfirmed merely because a conflicting source exists. This is semantic
model work, not keyword filtering or a canned no-advertising response.

Validate that layer against fresh useful, irrelevant, ambiguous and conflicting
contexts and then the downstream selector/expression path. Retain source binding,
expiry/withdrawal checks and NONE authority. Genuine learning integration follows
qualified operational utility, not simply more accepted proposals.
