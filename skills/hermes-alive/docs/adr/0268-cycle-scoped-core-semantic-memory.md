# ADR 0268 — Separately granted, cycle-scoped Core semantic memory

Date: 2026-10-28. Status: bounded controlled Native integration passed; real-model
semantics, longitudinal learning and production/distribution acceptance remain open.
Implements ADR0267's Native-read proposal; its separate automatic Core-worker
framing failure remains open.

## Boundary

An additional first-guidance choice, `--confirm-hermes-external-memory`, permits
semantic reads from this personal profile's already configured external Core
memory provider. Missing choices stay off; old curated-USER consent is not
expanded. The target must be private. Core retains provider selection,
dependencies, credentials, retrieval, scope and backend behavior. Alive uses
Core's loader and MemoryManager without requesting extraction or memory writes.
Initialization, recall bookkeeping and configured remote retrieval remain
Core/backend behavior, not a promise of zero database mutation.

A private model stage chooses at most one bounded semantic question from current
explicit context, current material and an admitted-input revision marker. It
receives no harvested transcript. A transient question cache avoids replanning
unchanged semantic inputs and clears on unload. Declined questions, malformed
proposals and empty returned context are distinct states; none proves absent
memories. Core owns model routing and fallback. Question observations retain
fingerprints and reported model metadata, not the question or response body.

Recall is provisional advice, not literal user input or execution permission.
Profile, grant and current Native authority are checked around IO and on use.
Temporary cycle context carries verified advice through existing cognitive
readers. Its shared close flag fences copied thread/async contexts after closure.
Child async phases publish to the parent's existing slot; setting only a child
ContextVar would lose the context at return. Advice is not imported as permanent
Alive memory. Protected generation records follow their selected retention.

Public discovery inquiry/planning readers explicitly exclude this new private
recall. Private cognition/review may use its advisory kind; the general review
prompt must not relabel all context as literal user statements. Grant changes
fence returned results. Core may retain physical prefetch IO after its timeout;
empty output or client shutdown never proves that IO terminated.

## Evidence and limits

r295 qualified the read capability with actual Core and an unmodified public
Holographic provider. r296 added context visibility, Core thread and child-async
contexts, closure, tampered content and public-reader exclusion. Earlier fixture
failures remain: r293 imported an executable fixture and assumed Core had not
created its home; r294's supposed foreign path equalled the current case path.
Neither supplied valid isolation evidence. Corrected cases assert different
resolved paths before attempting a read.

r297's empty public pool did not exercise cognition; its failed assertion cannot
establish memory delivery. r298 uses a synthetic listing through actual Core
setup/confirmation, installed Native, provider retrieval and cognitive dispatch.
Four independent cases pass: new grant, old curated-only grant, declined query
and malformed query. New-grant cognition sees a fact present only in the external
synthetic database, with its advisory kind. Old grants cause zero query-model
calls and no recall. Declined/malformed queries preserve cognition without
invented facts. A third unchanged wake does not replan the question. Captured
public search arguments contain neither the private fact nor semantic question.
Completed cycles expose no recall to later ordinary readers.

The same run passed ten capability/isolation cases plus existing setup,
discovery-inquiry, owner-context and cognitive-context regressions. Controlled
replies do not qualify real-model judgment or natural usefulness. No real
messages, accounts or model credentials were used. The actual automatic
Core-worker recall counterexample remains failing and unchanged. No Core or
provider source was patched; production configuration was not changed.
