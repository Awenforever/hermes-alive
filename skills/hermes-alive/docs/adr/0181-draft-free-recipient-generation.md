# ADR 0181: remove duplicate prose from recipient-intent generation

Date: 2026-10-19. Status: implemented; canonical qualification pending.

## Measured problem and bounded decision

The new-path real Qwen diagnostic ends in its original generation deadline after
one call, before reviews or delivery. Its system prompt is13628 characters and
user evidence17383. This measures size and failure, not proof of latency causation
or general model unavailability. Do not extend timeouts or sample until lucky.

Generation still requests illustrative prose plus a formal recipient plan and
appends modern guidance to a complete legacy task. After ADR0180 makes that draft
non-executable, remove the duplicated responsibility from NEW modern operations.
Use a separate concise modern task, no model-specific settings, no additional
judge and no deterministic fallback message. The system task is4873 characters;
source evidence, current checks, limits, authority and original deadline remain.
Preserve soft interests, outside-profile value, literal user feedback and its
ambiguity, abstention, temporal/source relationships and distinct outcome stages.

## Representation and recovery

Pin recipient-plan-v3 and intent-only-v1 in the original method; bind the output
mode again inside the encrypted bundle. Require expression-required-v1 too.
Unknown, downgraded or mismatched modes fail. New candidates need no draft text:
their content is a validated internal recipient-intent envelope containing the
actual plan, action kind and canonical source reference. It is structurally NOT
a channel action contract. No assembled placeholder or extracted sentence is
substituted for model wording. The expression stage still generates and validates
the only executable text. Optional bounded draft text from older callers can be
retained as provenance, but cannot influence this new intent's content or reviews.

The existing bounded content envelope accommodates a validated plan and canonical
URL; arbitrary untyped content retains its old capacity. Source/purpose/selection
consume the plan; final wording remains independently reviewed. Meaning definition
accepts the internal intent only after current original proposal validation. No
new database, action framework, sender, router or queue is introduced.

New structural correction uses proposal-shape-v2 admission (draft-free), the same
one-correction allowance and original deadline. Historical proposal-shape-v1 uses
its old draft-required admission, exact retained contracts and source windows.
Reopening never generates missing prose or rewrites a prior review.

## Qualification and limits

Eight focused adjacent suites pass with a draft-free actual-plan fixture and
non-executable content checks. The first new fixture compares a frozen nested
plan with JSON lists directly; normalize both to plain JSON for equality, without
changing persisted content. Preserve that failed test result. New structural
recovery covers draft-free correction, erasure, forged failure, cancellation,
withdrawal, timeout and no-respend reopening. An actual previous runtime builds
a controlled old structural-recovery journal; the new runtime reopens identical
content with zero added events/inference. This is an offline contract test, not
a production migration or real recommendation.

The first canonical regression stops on a commitment test's stale recipient-plan-v2
assertion, before its controlled model returns. Update that expectation to v3 and
also assert the output/execution bindings; do not weaken production admission or
describe the failed run as passing. Requalify the complete canonical artifact.

DeepSeek review is pending at this entry. It reuses authorized public evidence and

prompt alone establishes neither intelligence nor reliable latency. Next evaluate
complete wording and recipient contribution, then continue useful outcomes,
noise-resistant long-term memory/agenda/feedback, host embedding, migration and
the ten fresh complete clean-round requirement. Production remains unchanged.
