# ADR 0283 — Open a conversation with the substance of one point

Date 2026-11-04. Development candidate.

An isolated real-model run produced a share and continued it across two
actual Core turns. The share led with a concrete architectural idea, then
listed separate benchmark rows. Its reviewer marked the form as suitable.
The follow-up retrieved the original context, but described one component's
responsibilities too narrowly and used stronger language for some reported
capabilities than the excerpts justified. This is structural progress and
does not count as a quality pass.

For new discovery intents, give the author an explicit opening-turn purpose.
Choose the observation worth sharing now, give it enough detail to be clear,
and reserve optional background for a follow-up. An explicit request for
depth still takes precedence. The final reviewer evaluates whether each
detail serves that opening and can request the existing source-led revision
when the text reads like a report. There is no length gate.

The conversational review has a new immutable scope. Earlier synthesis
receipts retain their exact prompts, snapshots and verdict format on replay.
The continuation reference tells the main agent to preserve the scope of a
component's work when simplifying and to attribute source-reported results.
Conversation context still preserves exact text and the existing Core budget.

Require real-model evidence on fresh cases for quality. Controlled tests
verify routing, response contracts, historical replay and the revision path.

In the next regional news test, the new assessment rejected a list-like
opening and the correction produced a focused message. Its second assessment
returned an invalid structure, so the cycle stopped before submission. Use
the existing bounded review recovery for final wording. One malformed
response can lead to one fresh assessment of the same evidence within the
original stage and cycle budgets. Unsupported, uncertain and valid negative
findings still follow their ordinary paths. Store both the invalid response
and the recovered receipt under the existing protected evidence contract.

The expanded continuation instructions crowded out the source catalog under a
2,000-character Core hook cap. Condense them while retaining the attribution
and scope guidance. The cap remains owned by Core. The installed regression
must still see the exact share and the handle for a source omitted for space.

The next real continuity test kept the article's claims separate from direct
evidence, but introduced a historical cause after labeling the passage as
analysis. It also restated its main point several times. Give the main agent
a conversational default of one observation and its implication for a casual
follow-up. Ask it to name the basis for causal explanations or acknowledge
the gap. User requests for depth take precedence. Core still owns the main
turn and its delivery. Verify this guidance with fresh real follow-ups,
including one where the evidence supports a causal explanation.

A fresh model-inference monitoring trial produced a short opening after the
reviewer rejected an initial report-like draft. Both subsequent Core turns
recovered the source. The first treated a maximum cross-platform gap and a
model-generation comparison as interchangeable, then added an unrequested
section on first-token latency. The second corrected the comparison and
identified the coverage limits of the sources. This trial does not qualify.

The comparison failure is about what an estimate measures. Similar sizes
cannot justify an equivalence without compatible measurements, populations
and conditions. The reported engineering explanation is also an attribution,
while the monitoring result establishes a difference. A source witness
shows where a claim came from. Qualification still requires the wording to
preserve what the cited material actually establishes. Test this with both
an observational comparison and a genuine controlled comparison before
crediting the evidence boundary.

A paired synthetic trial then used the same twofold ratio for a randomized
cache intervention and uncontrolled service telemetry. The actual Core
follow-up rejected an equivalence and identified the conditions of the
intervention. It still expanded a null result in one separate workload
into a general claim that unique prefixes eliminate any speed effect.
Keep negative results within their tested scope as well. This fixture
tests reasoning under known evidence boundaries. It earns no credit
toward qualification on fresh sources.
