# ADR0200 — Recall attributed feedback without inventing a permanent profile

Status: partial implementation; qualification and automatic selection pending

## Observed gap

A controlled history retained an authorized earlier reply, but three newer
situational/quoted replies displaced both the literal pair and its tentative
interpretation from cognition. Restart reproduced the loss of visibility.
An isolated two-call Core model contrast recovered the qualified distinction
when given the original pair. This is input-availability evidence, not semantic
accuracy statistics, automatic profile learning, useful delivery or acceptance.

Do not solve this by enlarging the recent window, giving durable authority to
a model interpretation, counting politeness as enthusiasm, or treating silence
as dislike. Retained content and currently supplied evidence are different.

## Bounded archive and exact resolution

Keep the historical three-pair reader unchanged. Add a paged owner-scoped
catalog, scanning at most64 outcome records and returning at most16 previews
per page, with a24000-character page budget. Invalid/ineligible records still
advance the scan cursor. A continuation means more records may exist, not that
another eligible feedback item is guaranteed. A page is never a complete
inventory. Truncated previews are selection aids, not evidence of a preference,
identity, consent change or action permission.

Resolve selected event references to complete delivered-message/reply pairs,
with source time and retention. Authorize every requested reference before
reading any private body. Reject expired, erased, withdrawn, foreign, malformed
or changed groups as a whole. Never guess the most recent reply, silently drop
a difficult member or trim away qualifications. Up to eight unique references
are accepted; recent plus recalled context must fit eight pairs/12000 characters.
Exceeding this bound is incomplete work, not a reduced successful interpretation.

Current recent corrections remain alongside archived evidence. Interpret their
times and attributed meanings; an old preference cannot silently override a
new correction. Repeated representations are not independent observations.
This API does not create an interest fact or modify any preference weight.

## Concrete decision consumer and replay

Planning accepts exact recalled feedback references and binds them into its
operation before interpretation. Synthesis records exact-feedback-pairs-v1,
selected references and the complete context digest. Its evidence/retention
binding includes all admitted pairs, and currentness is checked before/after
model waits and on completed-operation recovery. Source/value assessment uses
the same recorded scope rather than reopening only today's recent window.
New source-led authoring also receives these literal pairs, never only their
model-written paraphrase. Repair operations keep the same reference scope.

No recall marker means the original historical contract. Old operations cannot
gain new context, new model work or new authority merely by reopening under
new code. Exact reference selection is currently a host input; an automatic
model selector and its durable acquisition/recovery wiring remain unfinished.
This partial consumer is NOT a claim that ordinary installed cognition now
automatically retrieves all relevant older feedback.

## Minimize unrelated reads

Feedback attribution previously enumerated/decrypted every outcome body on an
attempt before keeping only delivery receipts. A multi-reply archive stress
case exposed the resulting repeated work. Add an optional typed kind filter
to the existing projection query, keeping its old unfiltered default. Feedback
snapshot requests only delivery outcomes: their canonical evidence, source,
receipt and delivered-content validation remain mandatory. A kind filter is
not acceptance of an unvalidated receipt and does not change the snapshot's
meaning. Tests must reject decryption of unrelated reply-outcome details.

## Qualification and remaining objective

Controlled tests cover paging beyond the former64-record horizon, recent plus
archived pairs in actual interpretation/source-review inputs, exact replay,
source-linked candidate evidence, erasure during a model wait and on reopen,
foreign reference preflight, full long qualifications and no physical sends.
Mocks prove contract routing, not good automatic selection or user satisfaction.

Next complete durable, bounded semantic selection against current inquiry and
correction context, including paging exhaustion, contradictions and absence of
evidence. Preserve Hermes model/auth/provider ownership and existing configured
external memory integration; do not create a second private memory service.
Qualify actual installed paths and fresh real outcomes, not just helper tests.
Sustained agenda, reflection usefulness, erasure/migration/recovery/rollback,
cross-platform lifecycle, ten fresh complete clean rounds and production
acceptance all remain required. No deployment, release or Gateway restart is
authorized by this ADR.
