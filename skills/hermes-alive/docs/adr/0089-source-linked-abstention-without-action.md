# ADR 0089 — Source-linked abstention is an interpretation, not an action

Status: experimental kernel contract; no production deployment or semantic qualification.

## Distinction

Global ActionKind.SILENCE already exists in downstream deliberation. Reusing it
as an executable candidate for each skipped discovery source would conflate
per-source interpretation with cycle selection and does not solve missing
coverage. Opportunity synthesis now returns separate source-linked abstentions,
with source observation identity and a retained model reason. They are not
CycleCandidates, action contracts, preferences or delivery outcomes.

The prompt offers communication candidates plus non-actions and asks questions
only for a material uncertainty that could change a useful decision. A conflicting
source does not require reconfirming an existing explicit boundary. This is a
general model decision principle, not an advertisement keyword rule. Parsing
cannot prove that a reason or question is substantively correct.

## Representation and lifecycle

- At most four communication drafts and eight non-actions, bounded by the eight
  supplied owner-scoped discovery observations. Non-action reasons are nonblank,
  at most 512 characters, and preserved exactly, not truncated or invented.
- Unknown/foreign IDs, extra authority fields, duplicate skips, and a simultaneous
  proposal/skip for one source invalidate that skip. Good independent units survive.
  A conflicting communication draft remains subject to downstream selection; the
  interpreter never guesses that it should secretly become a skip.
- Missing/rejected decisions remain explicitly unassessed. A blank communication
  draft stays invalid and is not retroactively converted into an abstention.
- Rejected communication and abstention counts stay separate. Existing retained
  bundles without abstentions retain their original empty/nonempty meaning; this
  is data continuity, not an old-Hermes runtime compatibility requirement.
- Reasons stay in the encrypted proposal bundle, with expiry at the earliest
  discovery source expiry. Journal receipts store only counts and content reference.
  Recovery revalidates subject/clearance, original source/context/learning snapshot,
  bundle digest/expiry and counts. Erasure or changed evidence blocks reuse.
- No preference observation, automatic learning weight, action attempt, dispatch,
  recipient, scheduling or real-message permission is derived from a skip.

Probe reporting distinguishes reasoned abstention, empty model response, partial
rejection and unassessed IDs. These are observations, not semantic success labels.

## Prospective verification

Windows component regressions cover mixed draft/skip/missing coverage, exact
reason preservation, arbitrary non-keyword reasons, foreign/duplicate/conflicting
IDs, authority injection, length/blank errors, partial results, reopen equality,
encrypted retention and erasure. Existing synthesis/recovery/paired advice tests
also pass. Isolated Linux snapshot tests include expression, execution and learned
context as well as the new abstention suite. Fake tests are excluded from real
model-call counts and do not prove installation or production behavior.

Real experiment reuses the previous three public synthetic paired contexts to
test the changed contract, not three fresh user cases or independent samples.
No claim of ten clean full-chain calls, independent ground truth, longitudinal
utility or source-rationale superiority is permitted from this replication.

## Remaining work, unchanged scope

Semantic review must still assess unsupported claims, unnecessary questions,
missing useful decisions, and non-actions with misleading reasons. Fresh scenarios
and downstream selection/expression tests are required; prompt compliance is not
an interruption policy proof. Non-action coverage is not evidence of disinterest
or feedback. Bounded genuine feedback learning, authenticated host ingress and
delivery, long-term layered/external memory, sustained agenda/adaptation,
forgetting/migration/rollback, portable lifecycle and production acceptance retain
their full scope.
