# ADR 0140 — Remember literal feedback before certifying preferences

Status: isolated development; no production activation or learning qualification.
Date: 2026-10-15.

## Decision

The next interpretation should not have to reconstruct a person's meaning from
an unqualified model paraphrase. A new owner-scoped `FeedbackContextReader`
supplies exact paired delivered wording and complete retained reply, with time
and provenance. It reuses the existing canonical delivery/feedback snapshot and
requires current inbound-retention and consolidation consent. It also resolves
the feedback outcome's own content: an erased outcome cannot remain usable merely
because its inbound message is still retained.

This is literal conversational evidence, not a new permanent profile, preference
weight, learned hypothesis, consent or action permit. It does not run a second
model to interpret each reply or require per-message human acceptance. Existing
feedback synthesis and preference-learning authority boundaries remain unchanged.
Actual learning/reflection remains incomplete; this connects its evidential input.

## Meaning, time and limits

- Prompts distinguish politeness, situational refusal, material uncertainty and
  a genuinely explicit change. They do not encode keyword rules for meetings,
  thanks or particular interests. Model behavior on new pairs remains to qualify.
- Explicit memory context now carries the original source-observation times,
  not merely memory IDs. A newer literal correction must not be silently overruled
  by stale profile text; no utterance may bypass trusted policy/consent boundaries.
- The view scans at most 64 owner-scoped outcome records, emits at most three
  pairs and at most 6,000 JSON characters. Whole paired meaning is included or
  omitted, never truncated to remove a negation/qualification. This is a bounded,
  incomplete view, not proof that omitted feedback does not exist. Existing
  canonical-verifier internal work is not established as constant time.
- Original delivery attribution, complete retained input, owner, clearance,
  consent, content integrity and expiry must remain valid. Expected unavailable
  evidence is excluded; operational/database failures do not become an empty
  successful inventory. Foreign owner data is scoped out before content access.
- Data text is excluded from repr and structural journal receipts. Do not treat
  synthetic actor equality/receipts as real gateway owner-authentication proof.

## Recovery, provenance and privacy

Interpretation includes the pairs and binds their digest; full explicit context
including chronology also gains a digest. Both are rechecked after model await
and on reopen. Source-support review sees the same paired context. New candidates'
model-judgment evidence lists include the original feedback source and outcome
IDs; model dimensions remain judgments, never measured preferences or authority.
Receipts retain structural dependency IDs, not private text.

Derived opportunity content expires no later than the earliest included feedback
retention boundary or discovery source. Explicit deletion/withdrawal removes the
view and invalidates retained decisions. This does **not** finish physical cascade
erasure of every existing derived encrypted copy across vaults/backups; that
full-objective requirement remains open before production qualification. Do not
advertise the new expiry cap as complete forgetting or keep using invalidated data.

Older research completions without the new context digests recover only if the
corresponding new context is empty. Otherwise preserve the old audit record and
require a new explicit operation; this is not a tested production-state migration.

## Evidence

The synthetic composed fixture proves exact pair inclusion and memory chronology,
owner/clearance isolation, copied-owner refusal, candidate evidence lineage,
no upgraded authority, feedback-capped derived retention, current recovery,
in-flight source erasure refusal, erased outcome exclusion, consent withdrawal,
and no new memory/preference records or model-feedback interpretation calls.
An oversized pair is omitted without altering its original final qualification.
Read-spy assertions also prove no private content resolver is invoked for a
copied outcome belonging to another consenting owner or after consent withdrawal;
returning an empty view alone would not establish this pre-access boundary.
No adapter is invoked; signed fixture delivery records are not real IO.

The initial Linux regression wrapper retained the old facade exception class
while replacing its implementation module. Updating that private overlay facade
fixed the test wrapper; it was not a Core/plugin runtime defect. Subsequent
context, registered-intent, expression-history and final preparation/repair
regressions pass in the isolated retained-module environment. Final fixture and
cross-platform status are recorded in the living plan, not inferred from a marker.
Full CI, fresh installation and production acceptance have not been established.

Real-model counts remain 132 logical / 145 observed HTTP starts, zero real sends.
Next verify the meaning of situational feedback, courteous replies and explicit
corrections in fresh actual-model decisions, then useful retractable learning,
full-loop host lifetime and the remaining memory/agenda/privacy/migration gates.
