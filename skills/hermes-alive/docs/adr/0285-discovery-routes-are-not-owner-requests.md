# ADR-0285 — Discovery routes are not current owner requests

Date: 2026-11-05. Status: observed defect; implementation pending.

## Evidence

A real inherited-model trial on the search-alignment candidate selected a hosted
model update page while collecting open-source multimodal releases. The draft
contrasted two model updates, inferred an acceleration mechanism and a wider
trend not established by the retained excerpts, then told the recipient this
was not what they had searched for. No current owner research request existed:
the query was configured as the isolated proactive discovery route.

The final reviewer correctly withheld the unsupported extrapolations. It also
treated the collection query as the recipient's requested conversational focus.
The exact original draft and assessment remain in private audited evidence;
there was no adapter submission or main followup. This is a failed quality
trial, not an improvement credit for refusing it.

## Problem

Approved collection scope establishes what the host may search and disclose.
It does not establish that the user asked that question, nor require every
worthwhile discovery to match each search term. Conversely, a broad interest
cannot make an old or different result count as finding the intended development.
Current snapshots retain the query but do not explicitly distinguish its origin
and role at interpretation, authoring and final assessment. The result can be
both false conversational history and an unnecessarily narrow selection gate.

## Next change

Carry a typed, host-derived configured-discovery-route role through these same
existing stages. Preserve the exact collection scope and source provenance.
New interpretation receipts must bind the new semantics; old receipts and
review contracts retain their original prompts and reconstruction behavior.
Do not infer a current request from a query, an internal research hypothesis,
profile interest or a generated brief.

Assess a direct match separately from an honestly presented useful departure.
A concrete unexpected finding may justify the latter, including outside the
interest profile. It cannot inherit unsupported dates, mechanisms or importance,
or be presented as fulfilling a user request that was never supplied. Do not
require an outward explanation of search mismatch as the price of a pivot.
Keep factual support, communication fit and source-role assessment in the same
existing model call; no extra judge, keyword gate, topic quota, routing override
or relaxation of send authority follows from this change.

## Qualification required

Prove role propagation and old-contract cold recovery, then exercise actual Core
matched, useful-departure, unsupported-request-attribution and unresolved cases.
Controlled model output establishes runtime wiring only. Use fresh real material
to inspect the original share and ordinary main followups before claiming useful
selection or conversational success. Continue longitudinal memory and work gates
alongside sharing; passing this defect's controls cannot qualify the product.
