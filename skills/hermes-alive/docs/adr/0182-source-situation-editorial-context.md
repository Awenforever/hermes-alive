# ADR 0182: source situation informs editorial purpose, not a detail prohibition

Date: 2026-10-19. Status: implemented; qualification pending.

## Measured problem and decision

A real draft-free chain reaches technically supported final wording, but its plan
still mandates a lengthy abstract inventory and a collection-truncation disclosure.
The renderer correctly preserves those units. Shortening only the final message
would violate its meaning contract. Fix upstream editorial choice instead of
adding another judge, a phrase blacklist or an arbitrary message-length limit.

Use the existing trusted source-kind distinction to give generation and factual/
purpose snapshots an explicit communication situation. Discovery defaults to a
conversational contribution, while current explicit requests still control detail.
An external discovery source does NOT prove that the user never requested a report.
An admitted commitment uses its original request; unknown source scope stays
unknown. No inferred user preference, authority or hard interest gate is created.

The modern task explains that plan contents become required meaning: select what
serves a coherent contribution plus its essential qualifications, rather than
everything learned from the source. Interesting details can remain at the source.
Limit or omit an unnecessary side claim rather than add an operational disclosure
about not knowing it. Never hide material uncertainty, invent personal relevance,
force a hook/question/joke or apply blanket brevity to requested detail/reminders.

Pin origin-purpose-v1 in the original interpretation method and encrypted bundle;
validate agreement and require the existing draft-free intent contract. Only new
operations expose the situation in review snapshots. Existing factual/purpose
review prompts and old snapshot digests remain unchanged; old completed chains
recover without inference or additional journal events. No new store, queue,
sender, registry, agent or judge is introduced.

## Qualification and honest limits

Focused tests cover the discovery/default/explicit-detail distinction, admitted
commitment scope, unknown context, current source checks and the existing final
expression authorization path. A previous real complete shadow chain replays
unchanged under the new code in a private copy with zero calls/events/sends.

One early controlled timeout test fails its exact-two-call assertion without a
mode diagnostic. Preserve the failure; do not claim its historical timing cause
was proved. A deterministic shared-clock test now establishes that the deadline
can validly expire after the first invalid response but BEFORE correction starts.
The timed test checks TimeoutError, the upper invocation bound and no-respend
replay rather than requiring a second invocation after budget expiry. Other
provider/withdrawal/cancellation call-count assertions stay exact. Production
deadlines and retry allowances do not change.

New public discovery reads domestic community/video results and an outside-profile
science source. Select original pages before model evaluation: domestic agent
collaboration, relevant smoke/fire remote sensing, and a space-refueling control.
Do not force promotional/video headlines into recommendations to satisfy a China
quota, describe older publications as current, or confuse reading with watching.
Actual model evaluation is pending at writing; mechanical tests and the presence
of diverse sources do not prove useful selection or ten clean complete rounds.

Continue real recipient contribution, outcome/feedback, noise-resistant memory,
sustained agenda, host lifecycle, migration and full production acceptance. The
CLI integration still is not a qualified production read lease or autonomous host
embedding. Production, Core, model configuration, other plugins and wmw stay unchanged.
